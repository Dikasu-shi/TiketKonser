# TiketKonser

TiketKonser is a frontend project for browsing concerts, selecting tickets, and going through a simple ticket booking flow.

This is one of my portfolio projects while learning frontend development. The project is built with React and Vite and uses local mock data instead of a backend.

## Features

- Browse available concerts
- Search and filter concerts
- View concert details
- Select tickets
- Interactive seat selection
- Ticket reservation countdown
- Promo code
- Simulated payment with Virtual Account and QRIS
- Digital ticket with QR code
- My Tickets page
- Favorite concerts
- Simple login and register
- Responsive design

## Tech Stack

- React
- Vite
- Tailwind CSS
- React Router
- Framer Motion
- Lucide React
- React Context API

## Getting Started

Install the dependencies:

```bash
npm install
```

Run the development server:

```bash
npm run dev
```

Open [http://localhost:5173](http://localhost:5173) in your browser.

Build for production:

```bash
npm run build
```
